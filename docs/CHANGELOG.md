## v1.2.0 - 2026/10/14

### 引擎更新

- 新增 Qwen LiveTranslate 3.8 实时引擎，支持内置流式翻译、业务空间和地域设置，并处理原文与译文交错返回
- 移除已下架的 Gummy 引擎，默认改为阿里云 Paraformer Realtime v2，支持实时识别及外部翻译
- 自动迁移旧 Gummy 引擎和 API Key 配置；CLI 密钥参数改为 `--dashscope_api_key`

### 优化体验

- 将自定义翻译服务拆分为 Ollama 本地模型和 OpenAI API 兼容模型，分别保存两类服务的配置
- 重命名主进程与字幕引擎之间含义不准确的翻译参数，并为旧版应用配置提供自动迁移
- 为全部五个字幕引擎添加中英日模型描述，显示在模型设置顶部；描述框的背景和边框跟随主题色及明暗主题
- 为字幕引擎设置中的音频类型、启用录制、自定义引擎、启用翻译和更多设置添加中英日鼠标悬浮说明，翻译说明适配 Qwen LiveTranslate 的内置翻译行为
- 将翻译相关字段集中移至字幕引擎设置后半部分，在模型与翻译设置之间添加跟随所选服务变化的中英日翻译说明，沿用模型描述的主题样式
- 将启用录制与启用翻译开关放在同一行，保留两项的悬浮说明
- 修复浅色主题选择黑色主题色时，模型和翻译描述框背景过深导致文字难以辨认的问题
- 为业务空间 ID 和阿里云地域添加中英日鼠标悬浮说明，提示地域匹配要求及业务空间 ID 的环境变量回退行为
- 为字幕样式预览框右上角添加与字幕窗口相同样式的关闭图标，点击后同步关闭“显示预览”开关
- 点击关闭预览图标后显示提示，说明可在字幕样式设置中重新开启预览，并提供中英日文案
- 优化“项目关于”窗口：分区展示项目简介、版本和更新日期，添加带图标与说明的项目及文档入口，适配深浅主题并支持键盘访问
- “项目关于”顶部使用软件图标，为项目和文档链接显示完整地址，长地址支持自动换行；作者仅显示姓名
- “项目关于”新增更新日志入口，将项目仓库、用户手册、字幕引擎手册和更新日志四张卡片排成两行两列，并同步中英日文案
- “项目关于”的用户手册、字幕引擎手册和更新日志文件链接统一使用 GitHub 的 `blob/main` 路径
- 将软件设置中的 Qwen LiveTranslate 3.8 移到模型列表第一项，同步中英日选项顺序和用户手册
